Safety & Community Protections Overview

Purpose: This document is intended to clearly explain the safeguards currently in place in HuckHub and why those safeguards support healthy, low-friction growth for the Madison ultimate community.

Current Safety Controls in HuckHub

No In-App Messaging

HuckHub is not a chat platform. It helps players signal availability and then coordinate through existing communication channels off-platform.

User Blocking

Players can block other users directly in-app. Blocked users are removed from future visibility and interaction paths and are tracked by the admin account

User Reporting

Players can report inappropriate behavior with category + optional details to support moderation review.

Location Permission Control

Users can choose whether "Throw now" requests location pin. If disabled, the app prompts users to add preferred parks manually.

Contact Sharing Controls

Users control whether their email/phone number is shared (default private). This helps avoid oversharing and keeps user consent explicit.

Public-Park-Oriented Workflow

The product is designed around public parks and known throwing spots.

How HuckHub Is Intended to Be Used

  1. Reach out to players you already know or recognize. HuckHub works best as a lightweight coordination layer inside existing community trust networks.
  2. Use established channels to communicate. After seeing who is available, coordinate details over text, Facebook, Instagram, or other known channels.
  3. Treat HuckHub as an availability alert system, not a communication platform. Its main value is avoiding serial outreach and reducing the need to pre-plan throwingsessions in advance.

How Safety Features Benefit the Madison Ultimate Community

  • Lowers barriers for newer players: clearer controls make first-time use feel safer.
  • Reinforces Spirit of the Game values: respectful behavior is supported by moderation and accountability tools.
  • Keeps interactions local and practical: location and park tools focus users on nearby, public practice contexts.
  • Supports year-round engagement: players can more easily maintain throwing connections outside formal league windows.
  • Creates a healthier ecosystem: users who violate standards can be reported/blocked, protecting the broader group.

Suggested MUFA Positioning (if promoted publicly)

MUFA can present HuckHub as a community-built, safety-aware supplemental tool for skill development and player connection, with clear expectations:

  1. Use public locations and normal personal safety practices.
  2. Use in-app block/report tools immediately as needed.
  3. Create a MUFA moderation account to review reports and block/unblock users for added control.
  4. Prioritize familiar connections and move detailed coordination to existing communication channels.
  5. Treat HuckHub as a complement to league/community programming.

Bottom Line

HuckHub is intentionally designed to improve throwing opportunities while preserving user agency and safety controls. While risk cannot be completely eliminated, HuckHub includes practical, visible safeguards where currently none are systematically employed for non-HuckHub throwing sessions.
